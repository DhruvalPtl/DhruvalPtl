## 🚀 Featured Repositories

### ⚔️ [RewardForge](https://github.com/DhruvalPtl/rewardforge)
An autonomous, LLM-driven meta-learning framework inspired by NVIDIA's Eureka. It leverages Stable-Baselines3 (PPO) and Qwen-32B via the Groq API to dynamically rewrite environment reward functions based on real-time training telemetry.
* **Impact:** Reached a median reward of **+316 on LunarLander-v3** within 500k steps, beating published PPO literature baselines (+268 at 1M steps) while halving compute overhead.

### 📸 [FoodFake-30K](https://github.com/DhruvalPtl)
A large-scale, peer-reviewed computer vision dataset published on IEEE DataPort. Built to serve as a balanced benchmark (30,000 images) for deepfake and generative food image detection.
* **Pipeline:** Utilized Flux-2 Klein for generation, automated diverse prompt slots via local LLMs, applied a CLIP-based quality threshold (0.28), and enforced dataset integrity using perceptual hashing.

### 🤖 [Agentic RAG Bug Hunter](https://github.com/DhruvalPtl/infineon-hackathon-agentic-bug-hunter)
An autonomous 4-agent software debugging pipeline built during the Infineon Technologies Hackathon. Orchestrates Retrieval, Analysis, Correction, and QA Verification agents to hunt and repair C++ bugs using documentation-grounded RAG.
* **Tech:** Built using Pydantic-AI, LlamaIndex vector stores, BAAI embeddings, and FastMCP servers.

### 🧠 [Causal Deep Learning Experiments](https://github.com/DhruvalPtl)
An end-to-end PyTorch implementation of multilinear causal factor discovery based on arXiv:2301.00314v3. Structures unstructured data as multi-mode tensors to isolate invariant causal subspaces using Causal Capsules and Inverse Causal Networks.

### 🛠️ [TriVision Open Source Contribution](https://github.com/DhruvalPtl)
Proud contributor to the TriVision workbench—a unified PyQt6 CV workbench chaining 130+ algorithms across OpenCV and scikit-image.
